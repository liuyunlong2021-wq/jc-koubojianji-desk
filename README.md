# 口播剪辑与影片拉片

一个桌面 App，包含两套独立工作台：

- 口播剪辑：导入原视频，使用本地 FunASR 识别字幕，完成字幕校准、结构重排、重点大字、音乐和音效设置，最后用 FFmpeg 输出成片。
- 影片拉片：自动检测镜头边界并支持人工校正，使用 Gemini 分析逐镜画面、角色、场景、道具和视频语言，最终导出图片提示词、视频提示词或剧本文档。

两套工作台共用应用设置和 Gemini API Key，各自保存项目历史和工作状态。

## 影片拉片

基本流程：

```text
选择项目 → 导入影片 → 自动切镜 → 人工校正 → 确认镜头
  → 图片分析 / 资产提示词
  → 视频反推 / 全片总览 / 按 4–30 秒拼装并导出
```

“导入影片”支持本地视频和公开的单条视频链接。在线视频由 App 内置的 yt-dlp 下载，必要时使用内置 FFmpeg 合并音视频，再进入与本地视频相同的拉片流程。

当前限制：不支持播放列表、直播、登录/Cookie、会员或私密内容，也不把 yt-dlp 当作通用图片下载器。公开 MP4 下载和 Bilibili 已验证；新片场作品页实测返回 `403 Forbidden`，YouTube、抖音及 Windows/Linux 仍待验收。

## 开发

需要 Node.js 22、pnpm 10。

```bash
pnpm install
pnpm dev
```

验证：

```bash
pnpm exec vue-tsc --noEmit
pnpm test
```

## 项目文件

每个项目由用户选择的项目文件夹承载，媒体和文档统一写入：

```text
项目文件夹/
  .raw/jc-media/
    视频/
    文档/
    图片/
    音频/
```

成片位于 `.raw/jc-media/视频/`，项目文档位于 `.raw/jc-media/文档/`。应用数据、FunASR 环境和模型使用口播剪辑器自己的 `jc-koubojianji-desk` 路径，不读取视频翻译工作台数据。

## 本地识别

在应用右上角设置中检查并安装 FunASR。若系统已有兼容环境，应用会复用；否则安装到当前产品自己的应用数据目录。

## 构建

```bash
pnpm build
```

构建前会自动下载并校验固定版本的 yt-dlp。也可以单独执行：

```bash
pnpm setup:yt-dlp
```

安装包输出到 `release-koubojianji/<版本号>/`。

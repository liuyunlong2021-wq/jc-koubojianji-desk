## 产品边界

口播剪辑器只处理已经录好的口播视频：

```text
选择项目 -> 导入原视频 -> FunASR 识别字幕 -> 字幕校准与人工确认
-> 结构整理 -> 重点大字/音乐/音效 -> FFmpeg 生成成片
```

不把视频翻译、角色配音、剧集创作、资产生图和导演分镜作为本产品入口。独立产品可以复用底层 Electron、FunASR、FFmpeg 和项目路径能力，但不得读取或修改母项目的业务状态。

## 项目文件边界

每个用户项目的根目录由用户选择或创建，口播媒体和文档固定写入：

```text
<项目根>/
  .raw/jc-media/
    视频/    # 原视频与生成成片
    文档/    # 原始转写、校准稿、结构整理和字幕样式
    图片/
    音频/    # 背景音乐与重点词音效
```

应用级 API Key、FunASR 环境和模型缓存使用口播剪辑器自己的应用数据目录，不写入项目 Wiki，也不回退读取视频翻译工作台的数据目录。

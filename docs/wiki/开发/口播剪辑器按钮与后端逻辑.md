# 口播剪辑器按钮与后端逻辑

> 按当前代码记录每个按钮实际执行的逻辑。按钮名称与代码行为不一致时，以调用链为准；纯前端操作不冒充后端能力。

## 调用与存储总览

- 主页面：`src/views/TalkingHeadDesk/index.vue`；窗口按钮：`src/layout/default.vue`。
- 桥接与 IPC：`electron/preload.ts`、`electron/ipc.ts`。
- 业务后端：`electron/talking-head-project.ts`；云模型：`electron/talking-head-cloud.ts`；本地识别：`electron/funasr-installer.ts`、`electron/local-asr.ts`；导出：`electron/ffmpeg/index.ts`。
- 项目数据统一写在项目根目录 `.raw/jc-media/`：`文档/` 保存 JSON/SRT/ASS，`视频/` 保存原视频和成片，`音频/` 保存背景音乐与音效。
- “纯前端”表示没有 preload、IPC 或 Electron 调用；“生成时生效”表示当前只改页面状态，点击“生成成片”后才进入后端并持久化。

## 视频与字幕工作台

| 按钮/控件 | 调用链 | 实际逻辑 |
| --- | --- | --- |
| 上传口播视频 / 点击空视频区 | `chooseSource()` → `talking-head-source-choose` → `chooseTalkingHeadSource()` | 选择视频，用内置 FFmpeg 验证可读性/时长；必要时再选项目。原子复制为 `视频/原始口播.<扩展名>`，计算 SHA-256，更新 `项目.json`，清空字幕、结构和花字计划。取消不变。 |
| 更换视频 | `confirmReplaceSource()`，纯前端 | 只打开风险确认弹窗。 |
| 更换弹窗：取消 | 纯前端关闭 | 不改任何文件。 |
| 更换弹窗：确认更换 | `replaceSource()` → 同“上传口播视频” | 选中新视频后覆盖原视频并清空下游；在文件选择器取消则保留原项目。 |
| 视频原生播放控件 | Chromium `<video controls>` | 播放、暂停、拖动不走业务 IPC；`timeupdate` 只记录前端播放头。 |
| 点击字幕行 | `selectCue()`，纯前端 | 跳到 cue 开始前 200ms，播放到结束后 300ms 并自动暂停。 |
| 修改人工确认稿 | `@change="saveCues"` → `talking-head-cues-save` → `saveTalkingHeadCues()` | 重新拆分/规范化，校验 ID、时间轴、非空文字；原子写 `确认字幕.json`、`确认字幕.srt`、`项目.json`。任何字幕变化都会废弃旧结构计划和花字计划。 |
| 识别字幕 | `transcribe()` → 先 `funasr-subtitle-install-status`，再 `talking-head-transcribe` → `transcribeTalkingHeadSource()` | FFmpeg 提取 16kHz 单声道 PCM 到 `视频/原始口播.wav`；本地 Python/FunASR 识别字词时间戳，确定性拆分并去除上屏标点；写 `原始转写.json`、`原始转写.srt`、`项目.json`。没视频或引擎未就绪时阻止执行。 |
| 字幕校准预设 | 纯前端赋值 `semanticPrompt` | 只切换当前要求。 |
| 保存我的字幕预设 | `saveSemanticPreset()`，纯前端持久化 | 同名覆盖并写 `localStorage` 的 `jc-koubojianji-semantic-presets`，重启后恢复；空名称/内容不动作。 |
| 字幕校准 | `startSemanticCalibration()` → `talking-head-cues-calibrate` → `calibrateTalkingHeadCues()` → 云端 `/v1/chat/completions` | 发送全部 cue ID、文本和要求；模型只可逐 ID 校错，不得增删、合并或拆分。条数、顺序、ID、文本不完整即失败。成功写 `字幕校准记录.json`，只展示建议，不直接覆盖确认稿。 |
| 应用校准建议 | `applySemanticSuggestions()` → `saveCues()` | 按 cue ID 替换确认稿并保存；保存动作会废弃旧结构和花字。 |
| 撤销本次校准 | `undoSemanticCalibration()`，纯前端 | 清空未应用建议，不修改确认稿或记录文件。 |
| 恢复并采用 FunASR 原文 | `restoreRecognized()` → `talking-head-cues-restore-recognized` → `restoreTalkingHeadRecognizedCues()` | 从 `原始转写.json` 重建确认稿，再走统一字幕保存；无原始转写时报错。 |
| 确认字幕，进入结构编辑 | `confirmCaptions()` → `enterStructureWorkspace()` | 先保存、重载，再进入结构页；空字幕或保存失败不进入。 |

## 播放头字幕编辑

六个按钮都先由前端纯函数 `editTalkingHeadCues()` 计算，再统一经 `talking-head-cues-save` 落盘；后端仍执行规范化、校验和原子写入。

| 按钮 | 确定性规则与边界 |
| --- | --- |
| 在当前位置新增字幕 | 取“最后一条结束时间”和“播放头”较晚者为开始，创建 1 秒“人工新增字幕”。 |
| 在当前位置拆分所选字幕 | 有字词时间戳时取离播放头最近的词边界；没有时按播放头时间比例拆文字和时长。未选中或播放头不在字幕内时报错。 |
| 与下一条字幕合并 | 合并时间、识别文字、确认文字和字词数组；没有下一条时报错。 |
| 设为所选字幕开始 | 把开始时间限制在上一条结束和本条结束前 1ms 之间。 |
| 设为所选字幕结束 | 把结束时间限制在本条开始后 1ms 和下一条开始之间。 |
| 删除所选字幕 | 从字幕数组移除；剩余数据仍须通过后端 ID、时间和内容校验。 |

## 结构计划

| 按钮/操作 | 调用链与实际逻辑 |
| --- | --- |
| 点击片段 | `previewPlanCue()`，纯前端：原视频按 cue 播放，页面叠加字幕样式与花字；不是 FFmpeg 离线预览。 |
| 上移 / 下移 | `move()` → `savePlan()` → `talking-head-edit-plan-save` → `saveTalkingHeadEditPlan()`：调换 cue 并原子写 `结构编辑计划.json`、`项目.json`。源指纹不符、cue 集不完整或 ID 重复则拒绝。 |
| 拖动排序 | `dropCue()` → 同一结构保存链：把 cue 插到目标位置。 |
| 删除片段 / 恢复 | `toggle()` → 同一结构保存链：只增删 `removedCueIds`，不删除源字幕。 |
| 整理意见预设 | `selectEditorialPreset()`，纯前端：把 prompt 写入编辑意见。 |
| 保存我的整理预设 | `saveEditorialPreset()`，纯前端持久化：同名覆盖并写 `localStorage` 的 `jc-koubojianji-editorial-presets`，重启后恢复；默认“韭菜盒子”来自代码常量。 |
| 生成整理方案 | `generatePlan()` → `talking-head-edit-plan-generate` → `generateTalkingHeadEditPlanForProject()` → 云模型：只能重排/删除现有 cue，不得改写、合并、拆分、新增；后端过滤未知 ID、补齐遗漏 ID、拒绝重复并保存计划。 |
| 还原原始顺序 | `resetPlan()` → `savePlan()`：恢复 `sourceCues` 原顺序且全部保留；不是恢复 FunASR 原文。 |

## 花字与重点词

| 按钮/控件 | 调用链与实际逻辑 |
| --- | --- |
| AI 挑重点词 / 重新挑选 | `generateHighlights()` → `talking-head-highlights-generate` → `generateTalkingHeadHighlightsForProject()`：只消费结构计划中保留字幕；按信息、情绪、节奏三层挑选，不限固定数量；每 cue 最多一项、原文连续 2–8 字。后端逐项 FFmpeg 抽帧，再让多模态模型从五个位置选不遮主体的位置。结果先是建议，不落盘；必须先有有效结构计划。 |
| 点击花字文字/建议 | `previewHighlightItem()`，纯前端：播放对应 cue 并叠加花字。 |
| 替换智能建议 | `applyHighlight()` → `talking-head-highlights-save` → `saveTalkingHeadHighlightPlan()`：替换该 cue 花字并写 `花字方案.json`、`项目.json`；成功后才更新 UI。 |
| 应用全部建议 | `applyAllHighlights()` → 同一保存链：按 cue 合并后一次保存。 |
| 添加花字 / 编辑铅笔 | `openAddHighlight()`，纯前端：打开弹窗并绑定当前 cue；编辑时带入文字、模式、样式和位置。 |
| 原字幕摘取 / 自定义花字 | 纯前端切换模式：原字幕模式必须是确认字幕连续子串；自定义可为任意短句；均最多 24 字并绑定当前 cue 时间。 |
| 花字弹窗“添加” | `confirmAddHighlight()` → `talking-head-highlights-save`：后端校验源指纹、cue、每 cue 唯一、非空/24 字、原文命中、样式和位置；成功写花字计划，失败显示错误。 |
| 花字弹窗“取消” | 纯前端关闭，不保存。 |
| 样式下拉 | `changeHighlightStyle()` → 花字保存链：只允许“爆点黄”或“结论绿”。 |
| 左上/右上/左中/右中/上中 | `changeHighlightPosition()` → 花字保存链：立即保存合法位置。 |
| 移除重点大字 | `removeHighlight()` → 花字保存链：删除该 cue 花字。 |
| 大字大小滑杆 | 纯前端修改 `highlightScale`（0.7–1.3）；生成成片时才通过 ASS 生效。 |

## 成片、音乐与音效

| 按钮/控件 | 后端对应逻辑 |
| --- | --- |
| 原比例 / 竖屏 9:16 | 纯前端，生成时传入；9:16 后端生成 1080×1920 模糊背景加等比居中前景。 |
| 烧录字幕 | 纯前端，生成时决定是否生成并应用 `成片字幕.ass`。 |
| 字幕字体 | 启动时 `talking-head-fonts-list` 调 `fc-list`，失败用内置字体；选择本身生成时生效。 |
| 字体项右键收藏 | 只写 `localStorage` 的 `jc-koubojianji-font-favorites`，影响排序，不写项目。 |
| 字幕字体/大小/位置/加粗/描边/字色/描边色/花字大小 | 操作完成即调用 `talking-head-subtitle-style-save` → `saveTalkingHeadSubtitleStyle()`；后端规范范围和颜色，原子写 `字幕样式.json`、`项目.json`。保存失败显示“字幕样式保存失败”，不再等待生成成片。 |
| 导入/更换背景音乐 | `talking-head-background-music-choose` → `chooseTalkingHeadBackgroundMusic()`：选择常见音频，复制为 `音频/背景音乐.<扩展名>`，沿用原音量或默认 10%，更新 `项目.json`。 |
| 音乐播放控件 | Chromium `<audio controls>` 本地播放，当前滑杆音量试听，不走 FFmpeg。 |
| 音乐音量滑杆 | 松手 `talking-head-background-music-save` → `saveTalkingHeadBackgroundMusic()`：限制 0–30%，验证文件存在，更新 `项目.json`。 |
| 移除背景音乐 | 同一保存 IPC 但不传音乐：清除项目绑定，当前不删除旧音频文件。 |
| 重点词音效开关 | `talking-head-sound-effects-enabled` → `setTalkingHeadSoundEffectsEnabled()`：布尔值写 `项目.json`。 |
| 两个音效试听 | `talking-head-sound-effects-prepare` 把缺少的内置 WAV 补到 `音频/`，再由浏览器 `Audio` 播放；不改开关。 |
| 生成/重新生成成片 | `generateFinal()` 先保存结构与花字，再 `talking-head-compose` → `composeTalkingHeadEditPlan()` → `executeFFmpeg()`：校验设置、源指纹、有效结构和保留片段；按 cue 裁切并 concat；可烧录 ASS 字幕/花字、循环混背景音乐、按花字混音效（相邻至少 1200ms），最终 `alimiter` 限幅，以 H.264/AAC 输出 `视频/口播剪辑成片.mp4`。进度经 `talking-head-progress` 回传，失败不标成功。 |
| 打开成片文件夹 | `talking-head-output-show` → `showTalkingHeadOutput()` → `shell.openPath()`：打开 `.raw/jc-media/视频/`；只在本页面成功生成后显示。 |

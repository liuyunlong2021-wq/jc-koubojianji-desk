# 口播剪辑器独立化迁移清单

## 目标

将当前 `jc-koubojianji-desk` 分支变为可独立开发、构建、安装和发布的“口播剪辑器”。拆分后的产品不包含视频翻译、角色配音、翻译 Wiki 或短视频工厂创作工作流。

原开发分支的功能基线为 `fd652ad`；独立仓库基线提交为 `c5de753`。后续清理仅在本独立仓库进行，原开发分支继续作为可回退的完整基线。

## 当前边界

口播剪辑器的用户流程：

```text
选择项目 -> 导入原口播视频 -> FunASR 字幕识别 -> 语义校准与人工确认
-> 结构整理 -> 重点大字/音乐/音效 -> FFmpeg 输出成片
```

项目文件必须保持在：

```text
<项目目录>/.raw/jc-media/
  视频/
  文档/
  图片/
  音频/
```

## 阶段 2：创建独立仓库基线

1. 从当前分支创建一个新目录和新 Git 仓库，目录名使用 `jc-koubojianji-desk`。
2. 复制时保留全部文件，且不复制 `node_modules/`、`dist/`、`dist-electron/`、`release-koubojianji/`。
3. 在新仓库安装依赖后，先运行下列基线验收；未通过前不得删除翻译代码：

```bash
pnpm exec vue-tsc --noEmit
pnpm test
pnpm dev
```

4. 手工验收：创建/打开项目、导入横版与竖版视频、识别字幕、校准字幕、整理口播、生成重点大字、生成成片并打开输出目录。

阶段 2 已完成：依赖已在本仓库重新安装，`pnpm exec vue-tsc --noEmit` 与 `pnpm test` 通过（213/213），并已从本目录启动开发应用确认独立 appData 路径。

## 阶段 3：在新仓库删除

按以下组别删除，每组完成后都运行基线验收。

| 删除组 | 主要目标 | 保留注意事项 |
| --- | --- | --- |
| 翻译产品页面 | `src/views/Home/`、翻译侧栏、翻译路由残留 | 当前路由已只指向 `TalkingHeadDesk`，删除前确认无动态引用 |
| 翻译业务后端 | 已移除 `electron/video-translation.ts`、翻译专属 IPC 和 preload 契约 | 口播云调用位于 `electron/talking-head-cloud.ts` |
| 翻译配音与角色 | `electron/seed-audio.ts`、`electron/voice-library.ts`、翻译角色绑定、声音版本 IPC | 口播只需要原视频音轨、背景音乐和重点音效 |
| 翻译 Wiki/媒体工厂 | 翻译 Wiki、剧集、资产、导演、分镜、Pinterest 相关 IPC 与页面 | 与口播项目目录无关 |
| 翻译运行时与测试 | `src/runtime/videoTranslation*`、翻译配音/FFmpeg mock 测试 | 保留 `talkingHeadProject.test.ts` 和最小构建契约测试 |
| 共享云模块瘦身 | 从 `electron/cloud.ts` 移除翻译、配音、创作、Wiki 调用 | 保留 API Key 存储、文本/视觉 JSON 请求、口播四个函数 |

删除后应将下列名称替换为中性或口播名称：

```text
video-translation-asr.ts -> local-asr.ts
video-translation-* IPC -> 删除
translation 构建脚本别名 -> talking-head 或默认脚本
```
